# Research

Research, exploration, and meeting notes. One Markdown file per topic,
named `YYYY-MM-DD-topic.md` (for example `2026-10-16-lab-data-formats.md`).

Notes are working material. Once a finding is settled, move it into
[`CLAUDE.md`](../../CLAUDE.md) (rules) or
[`docs/agent/INDEX.md`](../agent/INDEX.md) (facts) and leave a one-line
pointer in the note.

Never put patient data here.
